Meridian loads a project folder into your browser's memory, indexes it, and answers questions with citations that open the exact file and line. It runs entirely in your browser: your API key talks straight to your provider, and the built-in local engine works with no key at all.

01

Capabilities

Context Engine

Drop in a project folder. Smart selection scores every file and packs the most relevant into a token budget, with a project map so large repos still fit. Projects can be saved and reloaded.

Trace

Every answer shows its reasoning path. Expand any conclusion to see the files and lines it cites, and export whole sessions as Markdown or self-contained HTML.

Private Core

There is no backend. Your files and questions go from your browser straight to the provider you pick (Anthropic, OpenAI, or your own OpenAI-compatible endpoint) under your own key. Close the tab and they're gone.

Signal Extraction

Ranks what deserves attention: broken imports, import cycles, untested load-bearing files, duplicate names. Each finding is pinned to file:line evidence, computed deterministically from the index with no model involved.

Instruments

The model can propose read-only actions: local searches, file inspections, git commands to copy. Each one runs only when you click it, and nothing ever executes a shell command.

Drift Watch

Compares this session's index against your last one and reports new, removed, and reshaped files plus symbol and import drift. The comparison uses a local fingerprint of paths and counts, never file contents.

02

The system

STAGE 01

Observe

You load repositories and documents straight into the workbench. Files are read into your browser's memory one by one, and you choose exactly what's in scope.

STAGE 02

Reason

Questions run against the loaded project. Every conclusion carries a trace, so the path from evidence to answer stays inspectable.

STAGE 03

Act

The model proposes read-only actions: searches, file inspections, git commands to copy. Each one waits for your approval, and none of them is shell execution.

04

Questions

Nowhere near us. Meridian has no backend, so your files, questions, and API key can't reach us. When you ask a question, your browser sends it, plus the files the context engine selected, directly to the provider you chose, under your own account. With the LOCAL engine, nothing leaves the tab at all. Details in the privacy policy.

A modern browser. For model answers, bring your own API key (Anthropic, OpenAI, or any OpenAI-compatible endpoint); keys are stored in your browser's localStorage and sent only to that provider. Or use no key at all: the LOCAL engine indexes your project and answers questions about definitions, references, relationships, and structure by deterministic search, with no AI and no network.

Meridian is free. Model usage is billed by your provider at their rates; the workbench shows a running cost estimate and supports an optional session spend limit. We recommend creating a key with a spend cap.

Every answer includes its trace. Evidence chips open the cited file at the cited lines, so you can read the source yourself. AI output can still be wrong; the trace exists so that verifying it is fast. If a trace can't be parsed, the answer says so.

Free to use, open to read.

The workbench is free during the beta. No signup, no account. The full source is on GitHub.
