SETTINGS

PROVIDER

This page's security policy only permits requests to api.anthropic.com, api.openai.com, and localhost, so remote custom endpoints (OpenRouter, a hosted vLLM) are blocked here. Use a localhost server, or self-host the workbench and add your endpoint's origin to connect-src in app.html.

ANTHROPIC API KEY

Stored in this browser's localStorage only, one key per provider, and sent to exactly one place: the selected provider's API endpoint. We never see it; there is no server on our side to see it with.

Recommended: create a key in a dedicated workspace with a monthly spend limit. This page loads no third-party scripts, but a spend-capped key keeps the worst case small.

MODEL

CONTEXT ENGINE

FULL sends every checked file whole. SMART sends a project map plus the files most relevant to each question, packed into a token budget; use it for medium and large projects.

SESSION SPEND LIMIT

Optional. When the estimated session total would cross this, Meridian asks before sending; it never hard-blocks. Estimates only; your provider bills actuals. 0 or blank = off.

FILE CAP

The most files Meridian loads into memory at once, across every repo in the workspace. Default 8,000. A higher cap uses more memory, and the ~300 MB text cap still applies. Takes effect on the next folder you load. Blank = default.

IGNORE PATTERNS

One pattern per line; * matches anything (e.g. *.test.ts, docs/*). Applied at ingest and saved with the project. Lines starting with # are comments.

DISPLAY

USAGE ANALYTICS

Off by default. When on, Meridian keeps a log of how you use it in this browser's IndexedDB: when you asked, the kind of question, the provider, LOCAL or model, timings, token counts the provider reported, how many repos were loaded, and when you created a share or added a repo. Never code, file paths or API keys. Nothing is sent anywhere unless you fill in your own endpoint below.

Question text is a separate switch. When on, each question is stored as you typed it, cut to 300 characters, with anything that looks like a key removed.

Send events to my own endpoint (optional, blank by default). For owners who self-host a collector. When this is filled in and analytics is on, the same events are POSTed as JSON to this URL (question text only if you store it). It is the only network request analytics ever makes; Meridian has no collection server of its own. Events from LOCAL mode are never sent. A failed send is dropped (the local log keeps it) and sending pauses before the next try. This page's security policy allows localhost only, so a remote collector needs a self-hosted copy with its origin added to connect-src.

LOCAL DATA

Everything Meridian stores in this browser: your API key(s), model choice, color mode, context settings, sidebar layout, ignore patterns, the terms-acceptance record, saved-project metadata in IndexedDB (selection and settings, never file contents) and, only if you turn it on, the usage log. Loaded file contents and the conversation live in memory only and vanish when the tab closes (question text is kept only if you switch on that usage-log option).

BEFORE YOU BEGIN

Meridian runs entirely in your browser.

  • No servers. We never receive your files, questions, or key; the page loads no third-party scripts.
  • Bring your own key. Anthropic, OpenAI, or a custom endpoint. Requests go straight from this browser to the provider and are billed to your account. Prefer no key? The LOCAL engine answers by deterministic search over your loaded files, with zero network.
  • Keys stay local. Stored in localStorage, sent only to the selected provider. Use a spend-limited key.
  • AI output can be wrong. Answers and traces are machine-generated and may be inaccurate or incomplete. Verify before you rely on them.

SHARE THIS PROJECT · NO SERVER

Anyone with the link can read this code.

  • A share link carries the files themselves: their paths, full text and last-modified times, compressed into the part of the address after #. Whoever has the link can read that code, and so can any chat app or inbox it passes through.
  • Browsers never send the part after # to a server. GitHub Pages, which hosts Meridian, never receives it, and neither do we. The recipient's browser unpacks it in their tab.
  • Never included: API keys, provider settings, this conversation, saved projects, or anything else this browser stores. Files that look like secrets (.env, private keys, credentials) start unticked.
