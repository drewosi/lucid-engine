MERIDIAN CODE WORKBENCH
for engineering leads and security reviewers
FREE BETA · NO BACKEND

Ask your codebase. We never get a copy.

Meridian is a browser-only code workbench. It indexes a project in tab memory and answers questions with citations that open the cited file and line. There is no Meridian server. Questions go straight from the browser to the model provider you already use, under your own key and terms, and LOCAL mode sends nothing at all.

02

Who it's for, and why no backend

WHO IT'S FOR
  • Engineering teams at mid-size and large companies, and the leads getting people productive in big or unfamiliar codebases.
  • Security and platform reviewers who sign off on anything that touches source.
  • Teams with data-residency or vendor-risk rules that rule out hosted code assistants.
WHY NO BACKEND
  • No vendor server holds your code, so there is no copy of ours to breach or retain.
  • Requests go from the browser straight to your provider, under your agreement, region and data terms.
  • Fewer parties for data-residency and vendor-risk reviews to clear: Meridian adds none that sees code.
  • Files live in tab memory only. Saved projects and workspaces keep metadata only.
03

For security and compliance reviews

every point is checkable in the source and the network inspector
WHERE CODE LIVES
In the browser tab's memory, gone when it closes. Saved projects and workspaces keep metadata only (names, counts, selection, settings) in that browser's IndexedDB.
WHAT LEAVES, AND WHEN
Only when you ask a model a question: the question, ticked files, earlier turns and line-numbered excerpts the local index found (from any loaded file, ticked or not, with GROUND on) go directly to your provider. SMART adds a project map. PREVIEW SEND shows the exact payload. LOCAL sends nothing.
OUR SERVERS
None. Static files on GitHub Pages: no accounts, no database, no telemetry to us. GitHub may log standard request data when the page loads.
MODEL PROVIDER
Anthropic, OpenAI or any OpenAI-compatible endpoint, under your key, agreement, region and data terms. Local models (LM Studio, Ollama) work on the hosted page with CORS enabled for this site (see the user guide). For a gateway or regional endpoint, self-host.
API KEYS
In that browser's localStorage, one per provider, sent only to that provider. Never in share links, bundles, exports or the usage log.
SHARE LINKS AND BUNDLES
The code travels inside the link, after the #, which browsers never send to a server. Anyone holding it can read it, and it can't be revoked. Secret-looking files start unticked.
USAGE ANALYTICS
Off by default; nothing recorded while off. When on: stored in the browser, no code, paths or keys, question text only with a second switch. JSON/CSV export. Optional send to your own endpoint only.
PAGE HARDENING
No third-party scripts. The security policy allows scripts from this site only and connections only to the two provider APIs and localhost. Refuses to run in a frame.
NOT OFFERED
No certifications, SSO, admin console, central policy controls, audit-log service or SLA. Free beta, run by one person.
